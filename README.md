# Análisis de clientes y comportamiento crediticio con Excel

## Descripción del proyecto

Proyecto académico desarrollado como trabajo final de la formación de Analista de Datos. El objetivo es explorar una base de datos de clientes y sus operaciones para obtener indicadores sobre actividad, características de los clientes y comportamiento crediticio.

El análisis se realizó en Microsoft Excel, utilizando fórmulas, funciones de búsqueda y cálculos estadísticos, junto con una hoja de preguntas y respuestas y un dashboard.

## Herramientas utilizadas

- Microsoft Excel
- Fórmulas y funciones de Excel
- Funciones de búsqueda y cálculos estadísticos
- Tablas y visualizaciones para resumir resultados

## Contenido del análisis

El libro de trabajo está organizado en hojas que incluyen:

- **DATASET PRINCIPAL:** base de datos utilizada para el análisis.
- **PREGUNTAS Y RESPUESTAS:** resolución de preguntas de negocio a partir de los datos.
- **DASHBOARD:** síntesis visual de indicadores y resultados.

Entre los temas explorados se encuentran:

- Clientes activos e inactivos.
- Distribución de clientes inactivos por género.
- Límites de crédito promedio según el tipo de tarjeta.
- Importe total de transacciones por cliente.
- Edad promedio de clientes activos, segmentada por género.
- Evaluación de aptitud crediticia según los criterios definidos en el trabajo.

## Algunos resultados

- Se identificaron **8.330 clientes activos**.
- Entre los clientes inactivos, se registraron **904 mujeres y 670 hombres**.
- El límite de crédito promedio varía según la categoría de tarjeta: Azul, Plata, Oro y Platino.
- Se identificó al cliente con el mayor importe acumulado de transacciones dentro de la base analizada.
- La edad promedio de los clientes activos resultó similar entre mujeres y hombres.

## Estructura del repositorio

El repositorio contiene el archivo de Excel del proyecto y este documento con la descripción del trabajo. Se incorporarán capturas del dashboard para facilitar la visualización de los resultados.
